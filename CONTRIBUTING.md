# Contributing

Contributions are welcome.

1. Open an issue to discuss larger changes.
2. Fork the repository and create a focused branch.
3. Use Node.js 26.x and npm 11+.
4. Run `npm test` and `npm run typecheck` before submitting.
5. Include tests and documentation for behavior changes.
6. Never commit secrets, credentials, personal data, or real environment files.

By submitting a contribution, you agree that it is offered under the repository's Apache-2.0 license.
